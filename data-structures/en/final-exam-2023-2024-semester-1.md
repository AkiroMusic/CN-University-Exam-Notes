## I. Multiple-Choice Questions (2 points each, 20 points total)

1\. The time complexity of searching for an element in an array is ()

a. O(1)  b. O(log n)  c. O(n)  d. O(n log n)

2\. Which of the following descriptions of a stack is correct ()

a. first-in, first-out  b. last-in, first-out  c. first-in, last-out  d. random access

3\. What is the maximum number of nodes on level n of a complete binary tree ()

a. n  b. 2^n  c. 2^(n-1)  d. n^2

4\. The time complexity of inserting a node into a linked list is ()

a. O(1)  b. O(log n)  c. O(n)  d. O(n log n)

5\. Among the following sorting algorithms, which has the best time complexity ()

a. bubble sort  b. insertion sort  c. selection sort  d. quicksort

6\. The average search time complexity of a hash table is ()

a. O(1)  b. O(log n)  c. O(n)  d. O(n log n)

7\. Among the storage structures for graphs, the one suited to representing sparse graphs is ()

a. adjacency matrix  b. adjacency list  c. multiple adjacency matrix  d. edge-set array

8\. The worst-case time complexity of searching for an element in a binary search tree is ()

a. O(1)  b. O(log n)  c. O(n)  d. O(n log n)

9\. In heapsort, the time complexity of building the max-heap is ()

a. O(1)  b. O(log n)  c. O(n)  d. O(n log n)

10\. Which of the following algorithms is a typical application of divide and conquer ()

a. linear search  b. binary search  c. depth-first search  d. quicksort
