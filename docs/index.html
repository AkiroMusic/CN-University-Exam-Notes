Features

What it does

Exam review notes for five Chinese university courses, collected in one repository: Advanced Mathematics (Parts 1 and 2), Linear Algebra, Data Structures, and Military Theory. Each subfolder was merged from its own standalone repository with the full commit history preserved, and every folder is self-contained.

∫

Advanced Mathematics I

Practice problem sets with full worked solutions, provided as PDF.

∑

Advanced Mathematics II

Chapters 8–12 exercises in Markdown and PDF, with an answer key.

🧮

Linear Algebra

An integrated exam paper (MD/PDF) plus the original paper and a detailed answer key.

🌲

Data Structures

Two final-review handouts refactored with Modern C++11: core theories, formulas, and high-frequency exam traps.

🎖️

Military Theory

An integrated exam scope, ready for RAG vector knowledge bases or direct AI import.

📦

Self-contained folders

Each folder was a standalone repository before the merge — full commit history preserved, nothing else needed.

🖨️

Render anywhere

Markdown files render directly on GitHub; the PDFs are print-ready.

Quick Start

How to use

  1. Clone the repository, or download just the folder you need — every folder is self-contained.
  2. Markdown files render directly on GitHub; read them in place.
  3. PDFs are print-ready for offline revision.
  4. Check the LICENSE file inside each folder: MIT everywhere except military-theory (CC0-1.0).

git clone https://github.com/AkiroMusic/CN-University-Exam-Notes.git
