Features

What it does

Exam review notes for six Chinese university courses, collected in one repository: Advanced Mathematics (Parts 1 and 2), Linear Algebra, Data Structures, University Physics, and Military Theory. Five subfolders were merged from standalone repositories with their full commit history preserved; University Physics was added directly. Every folder is self-contained.

∫

Advanced Mathematics I

Practice problem sets with full worked solutions, provided as PDF.

∑

Advanced Mathematics II

Chapters 8–12 exercises in Markdown and PDF, with an answer key.

🧮

Linear Algebra

An integrated exam paper (MD/PDF), the original paper and answer key, a concise exam-room version, a Problem 6 walkthrough, and quick-review notes.

🌲

Data Structures

Two final-review handouts refactored with Modern C++11, a past final exam with a question-by-question walkthrough, and a C++ linked-list deletion deep-dive.

⚛️

University Physics

A 14-chapter knowledge-point handbook, a formula overview, and 16 selected problems with step-by-step solutions.

🎖️

Military Theory

An integrated exam scope, ready for RAG vector knowledge bases or direct AI import.

📦

Self-contained folders

Five folders were standalone repositories before the merge, with full commit history preserved — every folder works on its own.

🖨️

Render anywhere

Markdown files render directly on GitHub; the PDFs are print-ready.

Quick Start

How to use

  1. Clone the repository, or download just the folder you need — every folder is self-contained.
  2. Markdown files render directly on GitHub; read them in place.
  3. PDFs are print-ready for offline revision.
  4. Check the LICENSE file inside each folder: MIT everywhere except military-theory (CC0-1.0).

项目简介

六门中国高校课程的考试复习笔记合集：高等数学（上/下）、线性代数、数据结构、大学物理、军事理论。其中五个子文件夹由独立仓库合并而来并保留完整提交历史，大学物理为直接新增；每个文件夹均自成一体。

∫

高等数学（上）

练习题及完整解析，提供 PDF 版本。

∑

高等数学（下）

第八至十二章习题，Markdown 与 PDF 双格式，附答案。

🧮

线性代数

整合版试卷（MD/PDF）、原版试卷与标准答案、精简考场版答题、第 6 题详解与期末速成笔记。

🌲

数据结构

两份以 Modern C++11 重构的期末复习讲义、一份期末真题与逐题解析，以及 C++ 单链表删除专题。

⚛️

大学物理

14 章知识点手册、公式总览，以及 16 道精选大题与分步解析。

🎖️

军事理论

精编整合考试范围，可直接构建 RAG 向量知识库或导入 AI。

📦

自成体系的文件夹

五个文件夹合并前都是独立仓库，完整提交历史已保留——每个文件夹都能单独使用。

🖨️

随处可读

Markdown 文件可在 GitHub 直接渲染，PDF 适合打印。
