## 第十二章：常微分方程 习题全解

### 1. 证明下列函数是相应的常微分方程的解：$y = e^x$ ， $e^{-x}\frac{\mathrm{d}y}{\mathrm{d}x} + y^2 - 2ye^x = 1 - e^{2x}$

**证明：**

由于 $y = e^x$，求导得 $\frac{\mathrm{d}y}{\mathrm{d}x} = e^x$。

将 $y$ 与 $\frac{\mathrm{d}y}{\mathrm{d}x}$ 代入微分方程左端（LHS）：

$$\text{LHS} = e^{-x} \cdot (e^x) + (e^x)^2 - 2(e^x) \cdot e^x = 1 + e^{2x} - 2e^{2x} = 1 - e^{2x}$$

左端等于右端（RHS），因此 $y = e^x$ 是该常微分方程的解。

### 2. 求下列常微分方程的通解

#### （1） $\frac{\mathrm{d}y}{\mathrm{d}x} = x(2y + 1)$

**解：** 可分离变量微分方程。

$$\frac{\mathrm{d}y}{2y+1} = x\mathrm{d}x \implies \frac{1}{2}\ln|2y+1| = \frac{1}{2}x^2 + C_1 \implies \ln|2y+1| = x^2 + C_2$$

$$2y+1 = C e^{x^2} \implies y = C e^{x^2} - \frac{1}{2}$$

#### （2） $\frac{\mathrm{d}y}{\mathrm{d}x} = \frac{y}{x} + \sqrt{\left( \frac{y}{x} \right)^2 + 1}$

**解：** 齐次微分方程。令 $y = ux \implies \frac{\mathrm{d}y}{\mathrm{d}x} = u + x\frac{\mathrm{d}u}{\mathrm{d}x}$。

$$u + x\frac{\mathrm{d}u}{\mathrm{d}x} = u + \sqrt{u^2+1} \implies x\frac{\mathrm{d}u}{\mathrm{d}x} = \sqrt{u^2+1} \implies \frac{\mathrm{d}u}{\sqrt{u^2+1}} = \frac{\mathrm{d}x}{x}$$

两边积分得：$\ln(u + \sqrt{u^2+1}) = \ln|x| + \ln C \implies u + \sqrt{u^2+1} = Cx$。

将 $u = \frac{y}{x}$ 代回：$\frac{y}{x} + \sqrt{\frac{y^2}{x^2}+1} = Cx \implies y + \sqrt{x^2+y^2} = Cx^2$。

#### （3） $\frac{\mathrm{d}y}{\mathrm{d}x} = 3y - 2$

**解：**

$$\frac{\mathrm{d}y}{3y-2} = \mathrm{d}x \implies \frac{1}{3}\ln|3y-2| = x + C_1 \implies 3y-2 = C e^{3x} \implies y = C e^{3x} + \frac{2}{3}$$

#### （4） $\frac{\mathrm{d}y}{\mathrm{d}x} = \frac{3y}{x} + \frac{x+1}{x}$

**解：** 标准一阶线性非齐次方程：$\frac{\mathrm{d}y}{\mathrm{d}x} - \frac{3}{x}y = 1 + \frac{1}{x}$。

积分因子 $I(x) = e^{\int -\frac{3}{x}\mathrm{d}x} = x^{-3}$。两边同乘 $x^{-3}$：

$$\frac{\mathrm{d}}{\mathrm{d}x}(y x^{-3}) = (1 + \frac{1}{x})x^{-3} = x^{-3} + x^{-4}$$

$$y x^{-3} = \int (x^{-3} + x^{-4})\mathrm{d}x = -\frac{1}{2}x^{-2} - \frac{1}{3}x^{-3} + C \implies y = -\frac{1}{2}x - \frac{1}{3} + Cx^3$$

#### （5） $\frac{\mathrm{d}y}{\mathrm{d}x} = \frac{2y}{x+1} + (x+1)^3$

**解：** 变形为 $\frac{\mathrm{d}y}{\mathrm{d}x} - \frac{2}{x+1}y = (x+1)^3$。

积分因子 $I(x) = e^{\int -\frac{2}{x+1}\mathrm{d}x} = (x+1)^{-2}$。两边同乘 $(x+1)^{-2}$：

$$\frac{\mathrm{d}}{\mathrm{d}x}\left[y (x+1)^{-2}\right] = (x+1)^3 \cdot (x+1)^{-2} = x+1$$

$$y (x+1)^{-2} = \int (x+1)\mathrm{d}x = \frac{1}{2}(x+1)^2 + C \implies y = \frac{1}{2}(x+1)^4 + C(x+1)^2$$

### 3. 求下列常微分方程的通解

#### (1) $\frac{\mathrm{d}^2 y}{\mathrm{d}x^2} + \frac{2}{1 - x} \frac{\mathrm{d}y}{\mathrm{d}x} = 0$

**解：** 可降阶的高阶微分方程。令 $p = \frac{\mathrm{d}y}{\mathrm{d}x}$，则 $\frac{\mathrm{d}p}{\mathrm{d}x} + \frac{2}{1-x}p = 0$。

$$\frac{\mathrm{d}p}{p} = \frac{2}{x-1}\mathrm{d}x \implies \ln|p| = 2\ln|x-1| + \ln C_1 \implies p = C_1(x-1)^2$$

由于 $p = \frac{\mathrm{d}y}{\mathrm{d}x}$，再次积分：

$$y = \int C_1(x-1)^2 \mathrm{d}x = C_1(x-1)^3 + C_2$$

#### (2) $2\frac{\mathrm{d}y}{\mathrm{d}x} \cdot \frac{\mathrm{d}^2 y}{\mathrm{d}x^2} = 1$

**解：** 令 $p = \frac{\mathrm{d}y}{\mathrm{d}x}$，方程变为 $2p \frac{\mathrm{d}p}{\mathrm{d}x} = 1 \implies 2p\mathrm{d}p = \mathrm{d}x$。

两边积分得：$p^2 = x + C_1 \implies p = \pm \sqrt{x+C_1}$。

即 $\frac{\mathrm{d}y}{\mathrm{d}x} = \pm \sqrt{x+C_1}$，再次积分得通解：

$$y = \pm \frac{2}{3}(x+C_1)^{\frac{3}{2}} + C_2$$

### 4. 证明：$y = (c_1 + c_2 x)e^{-2x} + \frac{1}{8}\sin2x$ 为方程 $\frac{\mathrm{d}^2 y}{\mathrm{d}x^2} + 4\frac{\mathrm{d}y}{\mathrm{d}x} + 4y = \cos2x$ 的通解

**证明：**

1.  **齐次方程通解验证**：特征方程为 $r^2+4r+4=0 \implies (r+2)^2=0$，重根 $r_{1,2}=-2$。
    
    对应对应的齐次通解为 $y_h = (c_1 + c_2 x)e^{-2x}$。
    
2.  **非齐次特解验证**：设特解 $y_p = \frac{1}{8}\sin2x$。求导：
    
    $$y_p' = \frac{1}{4}\cos2x, \quad y_p'' = -\frac{1}{2}\sin2x$$
    
    代入非齐次方程左端：
    
    $$\text{LHS} = -\frac{1}{2}\sin2x + 4\left(\frac{1}{4}\cos2x\right) + 4\left(\frac{1}{8}\sin2x\right) = \cos2x = \text{RHS}$$
    
    满足结构 $y = y_h + y_p$ 且包含两个独立任意常数，证毕。
    

### 5. 证明：$y = c_1 \cos x + c_2 \sin x - \frac{1}{3}x\cos2x + \frac{4}{9}\sin2x$ 为方程 $\frac{\mathrm{d}^2 y}{\mathrm{d}x^2} + y = x\cos2x$ 的通解

**证明：**

1.  **齐次部分**：特征方程 $r^2+1=0 \implies r=\pm i$，齐次通解为 $y_h = c_1 \cos x + c_2 \sin x$。
    
2.  **非齐次特解部分**：设特解 $y_p = -\frac{1}{3}x\cos2x + \frac{4}{9}\sin2x$。求导：
    
    $$y_p' = -\frac{1}{3}\cos2x + \frac{2}{3}x\sin2x + \frac{8}{9}\cos2x = \frac{5}{9}\cos2x + \frac{2}{3}x\sin2x$$
    
    $$y_p'' = -\frac{10}{9}\sin2x + \frac{2}{3}\sin2x + \frac{4}{3}x\cos2x = -\frac{4}{9}\sin2x + \frac{4}{3}x\cos2x$$
    
    代入方程左端：
    
    $$\text{LHS} = y_p'' + y_p = \left( -\frac{4}{9}\sin2x + \frac{4}{3}x\cos2x \right) + \left( -\frac{1}{3}x\cos2x + \frac{4}{9}\sin2x \right) = x\cos2x = \text{RHS}$$
    
    由于含有两个任意常数且形式完整，该式确为方程通解。
    

### 6. 求下列常微分方程的通解

#### (1) $\frac{\mathrm{d}^2 y}{\mathrm{d}x^2} - 3\frac{\mathrm{d}y}{\mathrm{d}x} + 2y = 0$

**解：** 特征方程 $r^2 - 3r + 2 = 0 \implies (r-1)(r-2) = 0 \implies r_1 = 1, r_2 = 2$。

通解为：$y = C_1 e^x + C_2 e^{2x}$。

#### (2) $\frac{\mathrm{d}^2 y}{\mathrm{d}x^2} - 3y = 0$

**解：** 特征方程 $r^2 - 3 = 0 \implies r = \pm\sqrt{3}$。

通解为：$y = C_1 e^{\sqrt{3}x} + C_2 e^{-\sqrt{3}x}$。

#### (3) $\frac{\mathrm{d}^2 y}{\mathrm{d}x^2} + 5\frac{\mathrm{d}y}{\mathrm{d}x} + 4y = x$

**解：**

1.  **齐次通解**：特征方程 $r^2+5r+4=0 \implies r_1=-1, r_2=-4 \implies y_h = C_1 e^{-x} + C_2 e^{-4x}$。
    
2.  **非齐次特解**：设特解 $y_p = Ax + B \implies y_p' = A, y_p'' = 0$。
    
    代入方程：$5A + 4(Ax + B) = x \implies 4Ax + (5A + 4B) = x$。
    
    对应系数相等：$4A = 1 \implies A = \frac{1}{4}$；$5A + 4B = 0 \implies B = -\frac{5}{16}$。
    
    通解为：$y = C_1 e^{-x} + C_2 e^{-4x} + \frac{1}{4}x - \frac{5}{16}$。
    

#### (4) $\frac{\mathrm{d}^2 y}{\mathrm{d}x^2} + y = 5e^{2x}$

**解：**

1.  **齐次通解**：特征方程 $r^2+1=0 \implies r=\pm i \implies y_h = C_1\cos x + C_2\sin x$。
    
2.  **非齐次特解**：设特解 $y_p = Ae^{2x} \implies y_p' = 2Ae^{2x}, y_p'' = 4Ae^{2x}$。
    
    代入方程：$4Ae^{2x} + Ae^{2x} = 5e^{2x} \implies 5A = 5 \implies A = 1$。
    
    通解为：$y = C_1\cos x + C_2\sin x + e^{2x}$。
