# CN-University-Exam-Notes

[![Website](https://img.shields.io/badge/site-akiromusic.github.io-6D82FF)](https://akiromusic.github.io/CN-University-Exam-Notes/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Exam review notes for Chinese university courses, collected in one repository: **Advanced Mathematics (Part 1 & 2)**, **Linear Algebra**, **Data Structures**, **University Physics**, and **Military Theory**. Five of the subfolders were merged from their own standalone repositories (full commit history preserved); University Physics was added directly.

| Folder | Course | Contents |
| :--- | :--- | :--- |
| [`advanced-mathematics-1/`](advanced-mathematics-1/) | Advanced Mathematics (Part 1) | Practice problem sets with full worked solutions (PDF) |
| [`advanced-mathematics-2/`](advanced-mathematics-2/) | Advanced Mathematics (Part 2) | Chapter 8–12 exercises in Markdown + PDF, with answer key |
| [`linear-algebra/`](linear-algebra/) | Linear Algebra | Integrated exam paper (MD/PDF), original paper and answer key, concise exam-room answers, Problem 6 walkthrough, quick-review notes |
| [`data-structures/`](data-structures/) | Data Structures | Two final-review handouts refactored with Modern C++11 (MD/PDF), a past final exam with a question-by-question walkthrough, a C++ linked-list deletion deep-dive |
| [`university-physics/`](university-physics/) | University Physics | 14-chapter knowledge-point handbook, formula overview, 16 selected problems with step-by-step solutions (MD/PDF) |
| [`military-theory/`](military-theory/) | Military Theory | Integrated exam scope, ready for RAG vector knowledge bases or direct AI import |

> **License note:** Everything is MIT-licensed — see the root [`LICENSE`](LICENSE); each folder carries its own copy.

> **Languages:** Every course folder has an `en/` subfolder with a complete English edition of its documents (Markdown + PDF); the folder root keeps the original Chinese editions. README files are bilingual, English first.

## Usage

- Clone or download the folder you need; every folder is self-contained.
- Markdown files render directly on GitHub; PDFs are print-ready.
- Prefer English? Read the files inside each folder's `en/` subfolder.
