# Concise Edition of Chinese Military Theory

Simplified and integrated the scope of military theory exam questions from Chinese universities, optimized for AI-assisted learning.

## Features

- **Exam-oriented** — Covers all key exam points from Chinese university military theory courses
- **AI-optimized** — Structured data suitable for RAG vector knowledge base or direct AI import
- **Concise** — Removes redundant content, keeps only exam-relevant material

## Usage

Directly import the markdown files into an AI assistant or vector database for enhanced Q&A accuracy.
