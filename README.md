# CN-University-Exam-Notes

Exam review notes for Chinese university courses, collected in one repository: **Advanced Mathematics (Part 1 & 2)**, **Linear Algebra**, **Data Structures**, **University Physics**, and **Military Theory**. Five of the subfolders were merged from their own standalone repositories (full commit history preserved); University Physics was added directly.

| Folder | Course | Contents |
| :--- | :--- | :--- |
| [`advanced-mathematics-1/`](advanced-mathematics-1/) | 高等数学（上） | Practice problem sets with full worked solutions (PDF) |
| [`advanced-mathematics-2/`](advanced-mathematics-2/) | 高等数学（下） | Chapter 8–12 exercises in Markdown + PDF, with answer key |
| [`linear-algebra/`](linear-algebra/) | 线性代数 | Integrated exam paper (MD/PDF), original paper and answer key, concise exam-room answers, Problem 6 walkthrough, quick-review notes |
| [`data-structures/`](data-structures/) | 数据结构 | Two final-review handouts refactored with Modern C++11 (MD/PDF), a past final exam with a question-by-question walkthrough, a C++ linked-list deletion deep-dive |
| [`university-physics/`](university-physics/) | 大学物理 | 14-chapter knowledge-point handbook, formula overview, 16 selected problems with step-by-step solutions (MD/PDF) |
| [`military-theory/`](military-theory/) | 军事理论 | Integrated exam scope, ready for RAG vector knowledge bases or direct AI import |

> **License note:** Everything except Military Theory is MIT-licensed (root [`LICENSE`](LICENSE)). [`military-theory/`](military-theory/) keeps its original [CC0-1.0](military-theory/LICENSE) license — see the license file inside each folder.

## Usage

- Clone or download the folder you need; every folder is self-contained.
- Markdown files render directly on GitHub; PDFs are print-ready.

# CN-University-Exam-Notes

中国高校课程考试复习笔记合集：**高等数学（上/下）**、**线性代数**、**数据结构**、**大学物理**、**军事理论**。其中五个子文件夹由各自的独立仓库合并而来（完整提交历史已保留），大学物理为直接新增。

| 文件夹 | 课程 | 内容 |
| :--- | :--- | :--- |
| [`advanced-mathematics-1/`](advanced-mathematics-1/) | 高等数学（上） | 练习题及完整解析（PDF） |
| [`advanced-mathematics-2/`](advanced-mathematics-2/) | 高等数学（下） | 第八至十二章习题（Markdown + PDF），附答案 |
| [`linear-algebra/`](linear-algebra/) | 线性代数 | 整合版试卷（MD/PDF）、原版试卷与标准答案、精简考场版答题、第 6 题详解、期末速成笔记 |
| [`data-structures/`](data-structures/) | 数据结构 | 两份以 Modern C++11 重构的期末复习讲义（MD/PDF）、一份期末真题与逐题解析、C++ 单链表删除专题 |
| [`university-physics/`](university-physics/) | 大学物理 | 14 章知识点手册、公式总览、16 道精选大题与分步解析（MD/PDF） |
