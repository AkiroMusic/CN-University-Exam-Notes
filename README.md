# Concise Edition of Chinese Military Theory
# 中国军事理论精简版

Simplified and integrated the scope of military theory exam questions from Chinese universities, optimized for AI-assisted learning.

精简整合了中国高校军事理论课程考试范围，经优化后可直接制作 RAG 向量知识库或导入 AI 以提高答题准确率。

## Features | 功能

- **Exam-oriented** — Covers all key exam points from Chinese university military theory courses —— 覆盖高校军事理论课程所有考点
- **AI-optimized** — Structured data suitable for RAG vector knowledge base or direct AI import —— 结构化数据，适合 RAG 向量知识库或直接导入 AI
- **Concise** — Removes redundant content, keeps only exam-relevant material —— 移除冗余内容，仅保留考试相关材料

## Usage | 使用方法

Directly import the markdown files into an AI assistant or vector database for enhanced Q&A accuracy.

将 Markdown 文件直接导入 AI 助手或向量数据库，以提高问答准确率。
