# 第1章 质点运动学

## 习题 1-4

### 【答案】

已知加速度 $a(t) = 4 + 3t$。在 $t=0$ 时，$x_0 = 2\text{ m}$，$v_0 = 5\text{ m}\cdot\text{s}^{-1}$。

由 $a = \frac{\text{d}v}{\text{d}t}$ 可得：
$$\text{d}v = a\,\text{d}t = (4 + 3t)\,\text{d}t$$

两边积分：
$$\int_{v_0}^{v} \text{d}v = \int_{0}^{t} (4 + 3t)\,\text{d}t$$
$$v - v_0 = 4t + \frac{3}{2}t^2$$
$$v(t) = v_0 + 4t + 1.5t^2 = 5 + 4t + 1.5t^2\quad(\text{m}\cdot\text{s}^{-1})$$

在 $t = 10\text{ s}$ 时，速度为：
$$v(10) = 5 + 4 \times 10 + 1.5 \times 10^2 = 195\text{ m}\cdot\text{s}^{-1}$$

由 $v = \frac{\text{d}x}{\text{d}t}$ 可得：
$$\text{d}x = v\,\text{d}t = (5 + 4t + 1.5t^2)\,\text{d}t$$

两边积分：
$$\int_{x_0}^{x} \text{d}x = \int_{0}^{t} (5 + 4t + 1.5t^2)\,\text{d}t$$
$$x - x_0 = 5t + 2t^2 + 0.5t^3$$
$$x(t) = x_0 + 5t + 2t^2 + 0.5t^3 = 2 + 5t + 2t^2 + 0.5t^3\quad(\text{m})$$

在 $t = 10\text{ s}$ 时，位置为：
$$x(10) = 2 + 5 \times 10 + 2 \times 10^2 + 0.5 \times 10^3 = 752\text{ m}$$

---

### 【解析】

1. **核心思路（微积分在运动学中的应用）**：
   * **微分方向**：位置 $x$ $\xrightarrow{\text{求导}}$ 速度 $v$ $\xrightarrow{\text{求导}}$ 加速度 $a$。
   * **积分方向**：加速度 $a$ $\xrightarrow{\text{积分}}$ 速度 $v$ $\xrightarrow{\text{积分}}$ 位置 $x$。
   * 本题中，题目给出了加速度 $a$ 随时间 $t$ 变化的函数，求速度和位置，因此我们需要沿**积分方向**连续进行两次积分。

2. **第一步：求速度 $v(t)$**
   * 加速度的定义式是 $a = \frac{\text{d}v}{\text{d}t}$。变形得：$\text{d}v = a\,\text{d}t$（表示极短时间内的速度变化量）。
   * 把两边累加起来（即积分）：左边积分上限为任意时刻速度 $v$，下限为初始速度 $v_0 = 5$；右边时间下限为 $0$，上限为任意时刻 $t$。
   * 积分计算：$\int (4 + 3t)\text{d}t = 4t + \frac{3}{2}t^2$。代入上下限后，移项整理得到速度公式：$v(t) = 5 + 4t + 1.5t^2$。
   * 将 $t=10\text{ s}$ 代入，直接算出速度 $v(10) = 195\text{ m/s}$。

3. **第二步：求位置 $x(t)$**
   * 速度的定义式是 $v = \frac{\text{d}x}{\text{d}t}$。同理变形得：$\text{d}x = v\,\text{d}t$。
   * 两边积分：左边从初始位置 $x_0 = 2$ 积到 $x$；右边从 $0$ 积到 $t$。
   * 积分计算：$\int (5 + 4t + 1.5t^2)\text{d}t = 5t + 2t^2 + 0.5t^3$。
   * 移项整理得到位置公式：$x(t) = 2 + 5t + 2t^2 + 0.5t^3$。
   * 将 $t=10\text{ s}$ 代入，直接计算出位置 $x(10) = 752\text{ m}$。

## 习题 1-6

### 【答案】

已知加速度 $a(t) = -A\omega^2 \cos\omega t$。在 $t=0$ 时，$v_0 = 0$，$x_0 = A$。

由 $a = \frac{\text{d}v}{\text{d}t}$，得：
$$\text{d}v = -A\omega^2 \cos\omega t\,\text{d}t$$

两边积分：
$$\int_{0}^{v} \text{d}v = \int_{0}^{t} -A\omega^2 \cos\omega t\,\text{d}t$$
$$v = \left[ -A\omega \sin\omega t \right]_0^t = -A\omega \sin\omega t$$

由 $v = \frac{\text{d}x}{\text{d}t}$，得：
$$\text{d}x = -A\omega \sin\omega t\,\text{d}t$$

两边积分：
$$\int_{A}^{x} \text{d}x = \int_{0}^{t} -A\omega \sin\omega t\,\text{d}t$$
$$x - A = \left[ A \cos\omega t \right]_0^t = A\cos\omega t - A$$
$$x(t) = A\cos\omega t\quad(\text{m})$$

故该质点的运动学方程为：
$$x = A\cos\omega t$$

---

### 【解析】

1. **什么是“运动学方程”？**
   * 运动学方程就是写出位置坐标随时间变化的函数关系式，即 $x = f(t)$。

2. **第一步积分（求速度 $v$）**：
   * 积分式为 $v = \int a\,\text{d}t = \int -A\omega^2 \cos\omega t\,\text{d}t$。
   * 提示：根据微积分基本公式，余弦函数的积分为正弦函数，即 $\int \cos(kx)\text{d}x = \frac{1}{k}\sin(kx)$。
   * 所以，$-A\omega^2 \cos\omega t$ 积分后得到 $-A\omega^2 \cdot \frac{1}{\omega}\sin\omega t = -A\omega \sin\omega t$。
   * 因为 $t=0$ 时 $v=0$，且 $\sin(0)=0$，所以常数项为 $0$。得到速度函数 $v(t) = -A\omega \sin\omega t$。

3. **第二步积分（求位置 $x$）**：
   * 对速度再进行一次积分：$x = \int v\,\text{d}t = \int -A\omega \sin\omega t\,\text{d}t$。
   * 提示：正弦函数的积分为负余弦函数，即 $\int \sin(kx)\text{d}x = -\frac{1}{k}\cos(kx)$。
   * 所以，$-A\omega \sin\omega t$ 积分后得到 $-A\omega \cdot \left(-\frac{1}{\omega}\cos\omega t\right) = A\cos\omega t$。
   * 注意**定积分的上下限代入**：
     左边：$\int_{A}^{x} \text{d}x = x - A$；
     右边：$\left[ A\cos\omega t \right]_0^t = A\cos\omega t - A\cos(0) = A\cos\omega t - A$。
   * 两边化简，消掉 $-A$，最终得到：$x = A\cos\omega t$。这就是该质点的运动学方程。

# 第2章 质点动力学

## 习题 2-7

### 【答案】

已知 $m = 1\text{ kg}$，力 $F(t) = 3 + 4t$，初始速度 $v_0 = 10\text{ m}\cdot\text{s}^{-1}$。

**（1）求 $0 \sim 2\text{ s}$ 内力的冲量 $I$：**
根据冲量的定义：
$$I = \int_{0}^{2} F\,\text{d}t = \int_{0}^{2} (3 + 4t)\,\text{d}t$$
$$I = \left[ 3t + 2t^2 \right]_0^2 = (3 \times 2 + 2 \times 2^2) - 0 = 14\text{ N}\cdot\text{s}$$

**（2）求 $t = 2\text{ s}$ 时质点的速度：**
根据动量定理：
$$I = \Delta p = mv - mv_0$$
$$14 = 1 \times v - 1 \times 10$$
$$v = 24\text{ m}\cdot\text{s}^{-1}$$

---

### 【解析】

1. **什么是冲量（Impulse）？**
   * 在物理学中，力对时间的累积效应叫做**冲量**。如果是恒力，冲量就是 $I = F \cdot \Delta t$；如果是随时间变化的变力，就需要用定积分来计算：$I = \int F\,\text{d}t$。

2. **第一问解析**：
   * 题目要求 $0 \sim 2\text{ s}$ 的冲量，我们将变力 $F = 3 + 4t$ 在时间区间 $[0, 2]$ 内进行定积分。
   * 积分计算：$\int (3 + 4t)\text{d}t = 3t + 2t^2$。
   * 代入上限 $t=2$ 和下限 $t=0$：$(3\times 2 + 2\times 4) - 0 = 6 + 8 = 14\text{ N}\cdot\text{s}$（冲量的单位是牛顿·秒）。

3. **第二问解析**：
   * **动量定理**指出：物体所受合外力的冲量，等于物体动量的增量，即 $I = \Delta p = p_{\text{末}} - p_{\text{初}} = mv_{\text{末}} - mv_{\text{初}}$。
   * 既然我们在第一问中求出了冲量 $I = 14\text{ N}\cdot\text{s}$，那么就可以直接列式：$14 = m(v - v_0)$。
   * 代入已知量 $m = 1\text{ kg}$，$v_0 = 10\text{ m/s}$，解方程得 $14 = 1 \times (v - 10) \implies v = 24\text{ m/s}$。

## 习题 2-10

### 【答案】

已知合力 $F(t) = 400 - \frac{4}{3} \times 10^5 t$，出枪口时速率 $v = 300\text{ m}\cdot\text{s}^{-1}$。

**（1）求子弹走完枪筒全长所用的时间 $t$：**
由题意，离开枪口时合力为零，即：
$$F(t) = 0 \implies 400 - \frac{4}{3} \times 10^5 t = 0$$
$$t = \frac{400 \times 3}{4 \times 10^5} = 3 \times 10^{-3}\text{ s}$$

**（2）求子弹在枪筒中所受力的冲量 $I$：**
$$I = \int_{0}^{t} F\,\text{d}t = \int_{0}^{3 \times 10^{-3}} \left( 400 - \frac{4}{3} \times 10^5 t \right)\,\text{d}t$$
$$I = \left[ 400t - \frac{2}{3} \times 10^5 t^2 \right]_0^{3 \times 10^{-3}}$$
$$I = 400 \times (3 \times 10^{-3}) - \frac{2}{3} \times 10^5 \times (9 \times 10^{-6})$$
$$I = 1.2 - 0.6 = 0.6\text{ N}\cdot\text{s}$$

**（3）求子弹的质量 $m$：**
由动量定理，设初始子弹静止（$v_0 = 0$）：
$$I = mv - mv_0 \implies I = mv$$
$$0.6 = m \times 300$$
$$m = 2 \times 10^{-3}\text{ kg} = 2\text{ g}$$

---

### 【解析】

1. **第一问：找时间 $t$**
   * 题目的突破口在“**子弹离开枪口处合力刚好为零**”。
   * 这意味着，在子弹飞出枪口的那个瞬间 $t$，受力 $F = 0$。因此直接建立方程 $F(t) = 0$，解出 $t = 0.003\text{ s}$（或者写成 $3\times 10^{-3}\text{ s}$，即 3 毫秒）。

2. **第二问：求冲量 $I$**
   * 依然利用变力冲量的积分定义，积分区间为子弹在枪管里运动的这段时间，即从 $0$ 积到 $3 \times 10^{-3}\text{ s}$。
   * 积分项 $400 - \frac{4}{3} \times 10^5 t$ 积分后为 $400t - \frac{2}{3} \times 10^5 t^2$。
   * 带入上限 $3\times 10^{-3}$：
     * 第一项 $400 \times 0.003 = 1.2$；
     * 第二项 $\frac{2}{3} \times 10^5 \times 9 \times 10^{-6} = \frac{2}{3} \times 0.9 = 0.6$；
     * 相减得到 $1.2 - 0.6 = 0.6\text{ N}\cdot\text{s}$。

3. **第三问：求子弹质量 $m$**
   * 子弹在枪筒中从静止（$v_0 = 0$）加速到出枪口速度 $v = 300\text{ m/s}$。
   * 应用动量定理：冲量 $I = \Delta p = m \cdot v$。
   * 已知 $I = 0.6\text{ N}\cdot\text{s}$，$v = 300\text{ m/s}$，所以 $m = \frac{I}{v} = \frac{0.6}{300} = 0.002\text{ kg} = 2\text{ g}$。

## 习题 2-16

### 【答案】

已知 $m = 2\text{ kg}$，变力 $F_x(x) = 4 + 6x$。在 $t=0$ 时，$x_0 = 0$，$v_0 = 0$。

**（1）求由 $x=0$ 到 $x=4\text{ m}$ 过程中力对物体所做的功 $W$：**
根据功的定义式：
$$W = \int_{x_0}^{x_1} F_x\,\text{dx} = \int_{0}^{4} (4 + 6x)\,\text{dx}$$
$$W = \left[ 4x + 3x^2 \right]_0^4 = (4 \times 4 + 3 \times 4^2) - 0 = 16 + 48 = 64\text{ J}$$

**（2）求在 $x=4\text{ m}$ 处物体的速度 $v$：**
根据动能定理：
$$W = \Delta E_k = \frac{1}{2}mv^2 - \frac{1}{2}mv_0^2$$
$$64 = \frac{1}{2} \times 2 \times v^2 - 0 \implies v^2 = 64$$
$$v = 8\text{ m}\cdot\text{s}^{-1}$$

**（3）求由 $x=0$ 到 $x=4\text{ m}$ 过程中变力的冲量 $I$：**
根据动量定理：
$$I = \Delta p = mv - mv_0$$
$$I = 2 \times 8 - 0 = 16\text{ N}\cdot\text{s}$$

---

### 【解析】

1. **第一问：变力做功的求法**
   * **功的定义**是力与位移的乘积。当力 $F_x$ 随位置 $x$ 发生变化时，我们必须通过对位置的积分来计算功，公式为 $W = \int F_x\,\text{d}x$。
   * 在本题中，积分区间是位置 $x$ 从 $0$ 变到 $4\text{ m}$。
   * 积分计算：$\int (4 + 6x)\text{d}x = 4x + 3x^2$。代入上限 $4$ 得到功 $W = 64\text{ J}$（焦耳）。

2. **第二问：求速度 $v$**
   * **动能定理**指出：合外力对物体做的功，等于物体动能的变化量（$\Delta E_k = E_{k\text{末}} - E_{k\text{初}}$）。
   * 因为初始时刻物体是静止的（$v_0 = 0$），所以初始动能为 $0$。
   * 列出式子：$W = \frac{1}{2}mv^2 \implies 64 = \frac{1}{2} \times 2 \times v^2 \implies v^2 = 64$，容易解得在 $4\text{ m}$ 处速度为 $8\text{ m/s}$。

3. **第三问：求冲量 $I$**
   * 这道题如果要用冲量定义 $I = \int F\text{d}t$ 算，会非常复杂，因为我们不知道力随时间 $t$ 变化的函数。
   * **捷径**：直接利用**动量定理**，冲量就等于动量的变化量 $\Delta p = mv - mv_0$。
   * 此时 $m = 2\text{ kg}$，末速度为刚才求出的 $8\text{ m/s}$，初速度为 $0$。
   * 轻松得出：$I = 2 \times 8 = 16\text{ N}\cdot\text{s}$。通过动能与动量的关系，避开了复杂的积分。

## 习题 2-18

### 【答案】

已知 $m = 0.5\text{ kg}$，运动方程为 $x = 5t$，$y = 0.5t^2$。

对时间 $t$ 求导，求得速度分量：
$$v_x = \frac{\text{d}x}{\text{d}t} = 5\text{ m}\cdot\text{s}^{-1}$$
$$v_y = \frac{\text{d}y}{\text{d}t} = t\text{ m}\cdot\text{s}^{-1}$$

在 $t_1 = 2\text{ s}$ 时，速度分量与速度大小平方为：
$$v_{x1} = 5\text{ m}\cdot\text{s}^{-1},\quad v_{y1} = 2\text{ m}\cdot\text{s}^{-1}$$
$$v_1^2 = v_{x1}^2 + v_{y1}^2 = 5^2 + 2^2 = 29\text{ m}^2\cdot\text{s}^{-2}$$

在 $t_2 = 4\text{ s}$ 时，速度分量与速度大小平方为：
$$v_{x2} = 5\text{ m}\cdot\text{s}^{-1},\quad v_{y2} = 4\text{ m}\cdot\text{s}^{-1}$$
$$v_2^2 = v_{x2}^2 + v_{y2}^2 = 5^2 + 4^2 = 41\text{ m}^2\cdot\text{s}^{-2}$$

根据动能定理，外力所做的功 $W$ 为：
$$W = \Delta E_k = \frac{1}{2}mv_2^2 - \frac{1}{2}mv_1^2$$
$$W = \frac{1}{2} \times 0.5 \times (41 - 29) = 0.25 \times 12 = 3\text{ J}$$

---

### 【解析】

1. **核心方法（巧妙利用动能定理）**：
   * 题目要求 $2\text{ s} \sim 4\text{ s}$ 内外力做的功。外力做功直接等于**动能的改变量**（动能定理）。因此我们只需要求出 $t=2\text{ s}$ 和 $t=4\text{ s}$ 两个时刻质点的速度大小即可。

2. **第一步：求速度分量**
   * 质点在平面上做二维运动，其速度由 $x$ 方向和 $y$ 方向共同合成。
   * $x$ 方向速度 $v_x$ 为位置 $x = 5t$ 对时间 $t$ 的求导，结果为恒定值 $5$。
   * $y$ 方向速度 $v_y$ 为位置 $y = 0.5t^2$ 对时间 $t$ 的求导，结果为 $t$。

3. **第二步：计算两个时刻的速度平方**
   * 速度大小的平方公式（勾股定理）：$v^2 = v_x^2 + v_y^2$。
   * 当 $t=2\text{ s}$ 时：$v_1^2 = 5^2 + 2^2 = 29$。
   * 当 $t=4\text{ s}$ 时：$v_2^2 = 5^2 + 4^2 = 41$。

4. **第三步：求功 $W$**
   * 动能变化量：$W = \frac{1}{2}m v_2^2 - \frac{1}{2}m v_1^2 = \frac{1}{2}m(v_2^2 - v_1^2)$。
   * 带入数据：$W = \frac{1}{2} \times 0.5 \times (41 - 29) = 0.25 \times 12 = 3\text{ J}$。

# 第3章 刚体的定轴转动

## 习题 3-6

> **补充说明：** 试卷原题中“求：”后面缺失了具体求解物理量。通常此类经典题目有两问：
> （1）释放瞬间的**角加速度** $\beta$；
> （2）棒转动到水平位置时的**角速度** $\omega$。以下给出这两个经典物理量的标准求解过程。

### 【答案】

已知 $l = 1\text{ m}$，对端点 $O$ 的转动惯量 $J = \frac{1}{3}ml^2$，初始释放角 $\theta = 60^\circ$。

```
   / (释放位置，与水平呈60度)
  / 
 /_ 60°
O ------------------- (水平位置)
```

**（1）求释放瞬间的角加速度 $\beta$：**
释放瞬间，重力 $mg$ 作用在棒的重心（中点 $\frac{l}{2}$ 处），对 $O$ 轴的力臂为 $d = \frac{l}{2}\cos 60^\circ$。
根据转动定律 $M = J\beta$：
$$mg \frac{l}{2} \cos 60^\circ = \frac{1}{3}ml^2 \beta$$
$$\frac{1}{2}g \cos 60^\circ = \frac{1}{3}l \beta$$
$$\beta = \frac{3g\cos 60^\circ}{2l} = \frac{3 \times 9.8 \times 0.5}{2 \times 1} = 7.35\text{ rad}\cdot\text{s}^{-2}$$

**（2）求棒转动到水平位置时的角速度 $\omega$：**
以 $O$ 点所在的水平面为重力势能零点。根据机械能守恒定律：
$$E_{k1} + E_{p1} = E_{k2} + E_{p2}$$
$$0 + mg \frac{l}{2} \sin 60^\circ = \frac{1}{2} J \omega^2 + 0$$
$$mg \frac{l}{2} \sin 60^\circ = \frac{1}{2} \left( \frac{1}{3}ml^2 \right) \omega^2$$
$$g \sin 60^\circ = \frac{1}{3}l \omega^2$$
$$\omega = \sqrt{\frac{3g\sin 60^\circ}{l}} = \sqrt{\frac{3 \times 9.8 \times \frac{\sqrt{3}}{2}}{1}} = \sqrt{25.46} \approx 5.05\text{ rad}\cdot\text{s}^{-1}$$

---

### 【解析】

1. **第一问：刚体转动定律的应用（求角加速度）**
   * 就像质点运动用 $F=ma$ 一样，刚体转动用**转动定律**：$M = J\beta$，其中 $M$ 是合外力矩，$J$ 是转动惯量，$\beta$ 是转动角加速度。
   * 重力 $mg$ 作用在棒的几何中心（即中点 $l/2$ 处）。重力是竖直向下的，转轴 $O$ 在左端，此时力臂（轴到力作用线的垂直距离）就是 $\frac{l}{2}\cos 60^\circ$。
   * 列出方程：重力矩 $M = mg \cdot \frac{l}{2}\cos 60^\circ$ 等于 $J\beta = \frac{1}{3}ml^2 \beta$。
   * 约去两边的质量 $m$ 和一个长度 $l$，代入数据计算即可得到 $\beta = 7.35\text{ rad/s}^2$。

2. **第二问：机械能守恒（求旋转到水平时的角速度）**
   * 棒向下摆动时，只有重力做功，所以**机械能守恒**（动能 + 势能 = 常数）。
   * 刚体的转动动能公式为 $E_k = \frac{1}{2}J\omega^2$。
   * 重心高度的变化：初始时重心在中点且向上倾斜 $60^\circ$，其高度为 $h = \frac{l}{2}\sin 60^\circ$；转到水平位置时，重心高度为 $0$。
   * 重力势能的减少量等于转动动能的增加量：$mg \Delta h = \frac{1}{2} J \omega^2$。
   * 代入数据，求得角速度 $\omega \approx 5.05\text{ rad/s}$。

---

## 习题 3-8

### 【答案】

已知 $m_1 = 0.46\text{ kg}$，$m_2 = 0.50\text{ kg}$，$R = 0.05\text{ m}$，从静止开始，在 $t = 5.0\text{ s}$ 内下降高度 $h = 0.75\text{ m}$。

重物做匀加速直线运动：
$$h = \frac{1}{2}at^2 \implies 0.75 = \frac{1}{2} a \times 5.0^2$$
$$a = \frac{2 \times 0.75}{25} = 0.06\text{ m}\cdot\text{s}^{-2}$$

滑轮的角加速度 $\beta$ 为：
$$\beta = \frac{a}{R} = \frac{0.06}{0.05} = 1.2\text{ rad}\cdot\text{s}^{-2}$$

分别对 $m_2$、$m_1$ 以及滑轮写出动力学方程（设绳张力分别为 $T_2$ 和 $T_1$，取 $g = 9.8\text{ m}\cdot\text{s}^{-2}$）：
对于 $m_2$（下降）：
$$m_2 g - T_2 = m_2 a \implies T_2 = m_2(g - a)$$
对于 $m_1$（上升）：
$$T_1 - m_1 g = m_1 a \implies T_1 = m_1(g + a)$$
对于滑轮（转动）：
$$(T_2 - T_1)R = J\beta$$

将 $T_2$ 和 $T_1$ 代入滑轮方程：
$$\left[ m_2(g - a) - m_1(g + a) \right] R = J \frac{a}{R}$$
$$J = \frac{R^2}{a} \left[ (m_2 - m_1)g - (m_2 + m_1)a \right]$$

代入数值：
$$J = \frac{0.05^2}{0.06} \left[ (0.50 - 0.46) \times 9.8 - (0.50 + 0.46) \times 0.06 \right]$$
$$J = \frac{0.0025}{0.06} \left[ 0.04 \times 9.8 - 0.96 \times 0.06 \right]$$
$$J = \frac{1}{24} \left[ 0.392 - 0.0576 \right] = \frac{1}{24} \times 0.3344 \approx 0.0139\text{ kg}\cdot\text{m}^2$$

---

### 【解析】

1. **第一步：求加速度 $a$ 和角加速度 $\beta$**
   * 重物下落是匀加速直线运动。已知初速度为 $0$，时间 $t=5\text{ s}$ 内下落了 $h=0.75\text{ m}$。
   * 利用运动学公式 $h = \frac{1}{2}at^2$，直接求出加速度 $a = 0.06\text{ m/s}^2$。
   * 因为绳子和滑轮之间没有滑动，滑轮边缘的线加速度就是重物的位移加速度 $a$，所以滑轮旋转的角加速度为 $\beta = \frac{a}{R} = 1.2\text{ rad/s}^2$。

2. **第二步：对系统进行受力分析（核心！）**
   * **注意**：由于滑轮有质量和转动惯量，两侧绳子的拉力 $T_1$ 和 $T_2$ 是**不相等**的（右侧 $m_2$ 重，所以 $T_2 > T_1$，拉着滑轮顺时针加速转动）。
   * 对左边 $m_2$：它向下加速，所以重力大于拉力：$m_2 g - T_2 = m_2 a$。
   * 对右边 $m_1$：它向上加速，所以拉力大于重力：$T_1 - m_1 g = m_1 a$。
   * 对滑轮：受力矩有 $T_2$ 的顺时针力矩 $T_2 R$ 和 $T_1$ 的逆时针力矩 $T_1 R$。合力矩为 $(T_2 - T_1)R$。根据转动定律，$(T_2 - T_1)R = J\beta$。

3. **第三步：联立消元求解 $J$**
   * 从前两个式子中分别表达出 $T_2$ 和 $T_1$，代入第三个式子里。
   * 整理出转动惯量 $J$ 的表达式，把题目中给出的质量、半径、重力加速度 $g=9.8$ 以及算出来的 $a$ 带入，计算得到 $J \approx 0.0139\text{ kg}\cdot\text{m}^2$。

## 习题 3-10

### 【答案】

已知 $m_1 = 5\text{ kg}$，$\theta = 30^\circ$，$\mu = 0.25$，$m_2 = 10\text{ kg}$，滑轮 $m = 20\text{ kg}$，半径 $R = 0.2\text{ m}$，且滑轮为圆盘（$J = \frac{1}{2}m R^2$）。

设重物的加速度大小为 $a$（$m_2$ 向下加速，$m_1$ 沿斜面向上加速），滑轮角加速度为 $\beta = \frac{a}{R}$。设 $m_1$ 端的绳子张力为 $T_1$，$m_2$ 端的绳子张力为 $T_2$。

对各物体列动力学方程：
1. 对于 $m_2$（竖直向下加速）：
   $$m_2 g - T_2 = m_2 a \quad \text{--- (1)}$$
2. 对于 $m_1$（沿斜面向上加速）：
   $$T_1 - m_1 g \sin\theta - f = m_1 a \quad \text{--- (2)}$$
   其中摩擦力 $f = \mu N = \mu m_1 g \cos\theta$。
3. 对于圆盘滑轮（顺时针转动）：
   $$(T_2 - T_1)R = J\beta = \left(\frac{1}{2}m R^2\right) \left(\frac{a}{R}\right) \implies T_2 - T_1 = \frac{1}{2}m a \quad \text{--- (3)}$$

将式 (1) 和 (2) 相加，并利用式 (3)：
$$(m_2 g - T_2) + (T_1 - m_1 g \sin\theta - \mu m_1 g \cos\theta) = (m_1 + m_2) a$$
$$m_2 g - (T_2 - T_1) - m_1 g(\sin\theta + \mu \cos\theta) = (m_1 + m_2) a$$
$$m_2 g - \frac{1}{2}m a - m_1 g(\sin\theta + \mu \cos\theta) = (m_1 + m_2) a$$

移项整理得加速度 $a$ 的公式：
$$a = \frac{m_2 - m_1(\sin\theta + \mu \cos\theta)}{m_1 + m_2 + \frac{1}{2}m} g$$

代入数据（取 $g = 9.8\text{ m}\cdot\text{s}^{-2}$）：
$$a = \frac{10 - 5 \times (\sin 30^\circ + 0.25 \cos 30^\circ)}{5 + 10 + \frac{1}{2} \times 20} \times 9.8$$
$$a = \frac{10 - 5 \times (0.5 + 0.25 \times 0.866)}{25} \times 9.8 = \frac{10 - 5 \times 0.7165}{25} \times 9.8$$
$$a = \frac{10 - 3.58}{25} \times 9.8 = \frac{6.42}{25} \times 9.8 \approx 2.52\text{ m}\cdot\text{s}^{-2}$$

求绳子张力：
将 $a$ 代入式 (1) 求 $T_2$：
$$T_2 = m_2(g - a) = 10 \times (9.8 - 2.52) = 72.8\text{ N}$$
将 $a$ 代入式 (3) 求 $T_1$：
$$T_1 = T_2 - \frac{1}{2}ma = 72.8 - \frac{1}{2} \times 20 \times 2.52 = 72.8 - 25.2 = 47.6\text{ N}$$

---

### 【解析】

1. **整体运动趋势分析**：
   * 挂在左边的重物 $m_2 = 10\text{ kg}$ 比较重，而斜面上的 $m_1 = 5\text{ kg}$ 较轻且受到斜面的阻碍。因此，系统必然向左运动，即 $m_2$ 向下加速，$m_1$ 沿着斜面向右上方向加速滑动。

2. **建立各部分的动力学方程**：
   * **对于斜面上的 $m_1$**：在沿着斜面方向上，受到绳子向上的拉力 $T_1$、重力沿斜面向下的分力 $m_1 g \sin\theta$、以及阻碍运动的反向摩擦力 $f$。
     根据摩擦力公式：$f = \mu N$，其中垂直斜面方向的压力 $N = m_1 g \cos\theta$。所以 $f = \mu m_1 g \cos\theta$。
     列出牛顿第二定律方程：$T_1 - m_1 g \sin\theta - \mu m_1 g \cos\theta = m_1 a$。
   * **对于悬挂的 $m_2$**：受向下的重力 $m_2 g$ 和向上的绳子拉力 $T_2$。
     列方程：$m_2 g - T_2 = m_2 a$。
   * **对于圆盘滑轮**：左右拉力不相等，产生转动力矩。
     $(T_2 - T_1)R = J\beta$。因为滑轮是均匀圆盘，其转动惯量公式为 $J = \frac{1}{2}mR^2$，将 $\beta = \frac{a}{R}$ 代入，消掉半径 $R$，简化为：$T_2 - T_1 = \frac{1}{2}ma$。

3. **解联立方程**：
   * 这是一个由三个方程组成的方程组，未知数是 $a$、$T_1$ 和 $T_2$。
   * 最快的方法是将前两个方程变形后代入第三个方程中，可以直接消去拉力，解得加速度 $a \approx 2.52\text{ m/s}^2$。
   * 算出加速度后，分别带入前面的分步方程中，就能轻松算出两条绳子的张力 $T_1 = 47.6\text{ N}$，$T_2 = 72.8\text{ N}$。

# 第6章 机械振动与机械波

## 习题 6-5

### 【答案】

已知周期 $T = 2\text{ s}$，振幅 $A = 0.06\text{ m}$，波速 $u = 2\text{ m}\cdot\text{s}^{-1}$。在 $t=0$ 时，$y_0 = -A = -0.06\text{ m}$。

**（1）求该质点的运动学方程：**
圆频率 $\omega$ 为：
$$\omega = \frac{2\pi}{T} = \frac{2\pi}{2} = \pi\text{ rad}\cdot\text{s}^{-1}$$
设简谐振动方程为：
$$y = A\cos(\omega t + \phi) = 0.06\cos(\pi t + \phi)$$
代入初值条件 $t=0, y = -0.06\text{ m}$：
$$-0.06 = 0.06\cos\phi \implies \cos\phi = -1 \implies \phi = \pi$$
故该质点的运动学方程为：
$$y = 0.06\cos(\pi t + \pi)\quad(\text{m})$$

**（2）求沿 $x$ 轴正方向传播的一维简谐波的波动表达式：**
波沿 $x$ 轴正方向传播，则各质点的振动相位落后。波动表达式为：
$$y(x, t) = A\cos\left[ \omega \left(t - \frac{x}{u}\right) + \phi \right]$$
将 $A = 0.06$、$\omega = \pi$、$u = 2$、$\phi = \pi$ 代入：
$$y(x, t) = 0.06\cos\left[ \pi \left(t - \frac{x}{2}\right) + \pi \right]\quad(\text{m})$$

**（3）求该波的波长 $\lambda$：**
$$\lambda = uT = 2 \times 2 = 4\text{ m}$$

---

### 【解析】

1. **简谐运动的基本方程形式**：
   * 简谐运动的通用公式为 $y = A\cos(\omega t + \phi)$。其中：
     * $A$ 是振幅（最大位移，已知为 $0.06$）。
     * $\omega$ 是角频率，和周期 $T$ 的关系是 $\omega = \frac{2\pi}{T}$，算出 $\omega = \pi$。
     * $\phi$ 是初相位（$t=0$ 时刻对应的角度状态）。

2. **第一问：找初相 $\phi$**
   * 题目说“$t=0$ 时，质点恰好处在负方向最大位移处”，意思是位移 $y = -A = -0.06\text{ m}$。
   * 带入简谐公式：$-0.06 = 0.06 \cos\phi \implies \cos\phi = -1 \implies \phi = \pi$。
   * 所以该质点的运动方程为 $y = 0.06\cos(\pi t + \pi)$（也可以利用三角函数公式简化写成 $y = -0.06\cos(\pi t)$）。

3. **第二问：求简谐波的波动表达式**
   * 波动是振动在空间中的传播。如果一列波向 $x$ 轴**正方向**传播，那么距离原点 $x$ 处的质点，它的振动会比原点**落后**一段时间 $\Delta t = \frac{x}{u}$（路程除以波速）。
   * 所以我们只需要把原点质点振动方程中的时间 $t$ 替换为 $\left(t - \frac{x}{u}\right)$ 即可！
   * 直接替换：$y = 0.06\cos\left[\pi \left(t - \frac{x}{2}\right) + \pi\right]$。这就是非常经典的波动表达式写法。

4. **第三问：求波长 $\lambda$**
   * 波长就是波在一个周期内传播的距离：$\lambda = \text{波速} \times \text{周期} = u \times T$。
   * 已知 $u = 2\text{ m/s}$，$T = 2\text{ s}$，所以波长 $\lambda = 4\text{ m}$。

   * **波速 $u$**：图上直接标明了 $u = 0.08\text{ m/s}$。

# 第9章 静电场

## 习题 9-9

### 【答案】

已知两层假想同心球面半径分别为 $R_1 = 0.1\text{ m}$，$R_2 = 0.2\text{ m}$，电荷体密度 $\rho = 10^{-9}\text{ C}\cdot\text{m}^{-3}$。

根据球对称性，选取同心球面为高斯面。高斯定理形式为：
$$\oint_{S} E\,\text{d}S = E \cdot 4\pi r^2 = \frac{\sum q_{\text{内}}}{\varepsilon_0}$$
$$E = \frac{\sum q_{\text{内}}}{4\pi \varepsilon_0 r^2}$$

**（1）当 $r = 5\text{ cm} = 0.05\text{ m}$ 时：**
由于 $r < R_1$，高斯面内包围的电荷量 $\sum q_{\text{内}} = 0$。
故：
$$E_1 = 0$$

**（2）当 $r = 15\text{ cm} = 0.15\text{ m}$ 时：**
由于 $R_1 < r < R_2$，高斯面内包围的电荷为半径从 $R_1$ 到 $r$ 的球壳内的电荷：
$$\sum q_{\text{内}} = \rho V' = \rho \cdot \frac{4}{3}\pi (r^3 - R_1^3)$$
故该处的电场强度为：
$$E_2 = \frac{\rho \cdot \frac{4}{3}\pi (r^3 - R_1^3)}{4\pi \varepsilon_0 r^2} = \frac{\rho(r^3 - R_1^3)}{3\varepsilon_0 r^2}$$
代入数据（取 $\varepsilon_0 \approx 8.85 \times 10^{-12}\text{ C}^2\cdot\text{N}^{-1}\cdot\text{m}^{-2}$）：
$$E_2 = \frac{10^{-9} \times (0.15^3 - 0.1^3)}{3 \times 8.85 \times 10^{-12} \times 0.15^2} = \frac{10^{-9} \times (0.003375 - 0.001)}{3 \times 8.85 \times 10^{-12} \times 0.0225}$$
$$E_2 = \frac{10^{-9} \times 0.002375}{5.97375 \times 10^{-13}} \approx 3.98\text{ V}\cdot\text{m}^{-1}$$

**（3）当 $r = 50\text{ cm} = 0.5\text{ m}$ 时：**
由于 $r > R_2$，高斯面内包围了全部带电球壳的电荷：
$$\sum q_{\text{内}} = \rho \cdot \frac{4}{3}\pi (R_2^3 - R_1^3)$$
故该处的电场强度为：
$$E_3 = \frac{\rho(R_2^3 - R_1^3)}{3\varepsilon_0 r^2}$$
代入数据：
$$E_3 = \frac{10^{-9} \times (0.2^3 - 0.1^3)}{3 \times 8.85 \times 10^{-12} \times 0.5^2} = \frac{10^{-9} \times (0.008 - 0.001)}{3 \times 8.85 \times 10^{-12} \times 0.25}$$
$$E_3 = \frac{7 \times 10^{-12}}{6.6375 \times 10^{-12}} \approx 1.05\text{ V}\cdot\text{m}^{-1}$$

---

### 【解析】

1. **核心工具：高斯定理**
   * 在静电场中，如果电荷分布具有高度对称性（比如球体、球壳、无限长圆柱），求电场强度的不二法门就是**高斯定理**。
   * 高斯定理公式：穿过封闭曲面（高斯面）的电通量 $\oint E\text{d}S$ 等于该面内包围的所有净电荷 $\sum q_{\text{内}}$ 除以真空介电常数 $\varepsilon_0$。
   * 对于球对称分布，我们选一个半径为 $r$ 的同心球面作为高斯面。在这个面上，电场强度 $E$ 的大小处处相等且垂直于表面，因此积分部分可以直接化简为 $E \cdot (4\pi r^2)$（电场乘以球表面积）。
   * 求解公式统一为：$E = \frac{\sum q_{\text{内}}}{4\pi \varepsilon_0 r^2}$。我们只需要分析**不同半径的高斯面里面圈住了多少电荷**。

2. **第一问：$r=5\text{ cm}$（在内球面内部）**
   * 所有的电荷都分布在 $10\text{ cm} \sim 20\text{ cm}$ 之间的夹层中。
   * 半径为 $5\text{ cm}$ 的高斯面内部空空如也，包围的电荷 $q_{\text{内}} = 0$。因此，内部电场强度直接就是 $0$。

3. **第二问：$r=15\text{ cm}$（夹在中间）**
   * 这个高斯面圈住了部分电荷。具体来说，圈住了从内半径 $10\text{ cm}$（$0.1\text{ m}$）到当前半径 $15\text{ cm}$（$0.15\text{ m}$）这一段厚度的带电球壳。
   * 带电体积：$V' = \frac{4}{3}\pi r^3 - \frac{4}{3}\pi R_1^3$。电荷量就是体积乘以电荷体密度 $\rho$。
   * 带入高斯定理公式消去常数后：$E = \frac{\rho(r^3 - R_1^3)}{3\varepsilon_0 r^2}$。代入数值计算可得 $E \approx 3.98\text{ V/m}$。

4. **第三问：$r=50\text{ cm}$（在外面）**
   * 此时高斯面非常大，把整个带电夹层（$10\text{ cm} \sim 20\text{ cm}$）全部圈在了里面。
   * 被圈住的总电荷是固定的，对应整个球壳的体积：$V_{\text{总}} = \frac{4}{3}\pi (R_2^3 - R_1^3)$。
   * 同样带入高斯定理公式：$E = \frac{\rho(R_2^3 - R_1^3)}{3\varepsilon_0 r^2}$。代入 $r=0.5\text{ m}$ 进行计算，得到 $E \approx 1.05\text{ V/m}$。

## 习题 9-12

### 【答案】

根据“无限长”带电圆柱体的轴对称性，选取半径为 $r$、长度为 $L$ 且与圆柱同轴的圆柱面作为闭合高斯面。

高斯定理：
$$\oint_{S} \boldsymbol{E} \cdot \text{d}\boldsymbol{S} = E \cdot 2\pi r L = \frac{\sum q_{\text{内}}}{\varepsilon_0}$$

**（1）当 $r < R$（圆柱体内）时：**
高斯面内包围的电荷量为：
$$\sum q_{\text{内}} = \rho \cdot \pi r^2 L$$
代入高斯定理中：
$$E \cdot 2\pi r L = \frac{\rho \cdot \pi r^2 L}{\varepsilon_0} \implies E = \frac{\rho}{2\varepsilon_0} r$$

**（2）当 $r \geq R$（圆柱体外）时：**
高斯面内包围了该段圆柱体内的全部电荷：
$$\sum q_{\text{内}} = \rho \cdot \pi R^2 L$$
代入高斯定理中：
$$E \cdot 2\pi r L = \frac{\rho \cdot \pi R^2 L}{\varepsilon_0} \implies E = \frac{\rho R^2}{2\varepsilon_0} \frac{1}{r}$$

**（3）$E$-$r$ 曲线：**
* 在 $r < R$ 区间内，$E$ 与 $r$ 成正比（线性上升趋势）。
* 在 $r \geq R$ 区间内，$E$ 与 $r$ 成反比（双曲线下降趋势）。
* 在 $r = R$ 处电场达到最大值 $E_{\text{max}} = \frac{\rho R}{2\varepsilon_0}$。

```
 E 
 ^      /|
 |     / | \
 |    /  |  \
 |   /   |   \
 +--/----+----> r
 0       R
```

### 【解析】

1. **高斯面怎么建？（柱对称性）**
   * 对于“无限长”圆柱体，它的电场线是水平向外辐射出来的，像刺猬一样。
   * 我们建一个同轴的、半径为 $r$、高为 $L$ 的**圆柱形罐头盒**作为高斯面。
   * 电场只穿过这个“罐头”的侧面，不穿过上下底面。
   * 罐头的侧面积是 $2\pi r L$，所以穿过高斯面的总电通量就是 $E \cdot (2\pi r L)$。

2. **第一阶段：在圆柱内部（$r < R$）**
   * 高斯圆柱罐头只装了里面的一部分带电圆柱。
   * 这一部分圆柱的体积为 $\pi r^2 L$，所以里面的电荷量为 $q_{\text{内}} = \rho \cdot \pi r^2 L$。
   * 代入高斯公式：$E \cdot 2\pi r L = \frac{\rho \cdot \pi r^2 L}{\varepsilon_0}$。
   * 两边消去 $\pi, r, L$，得到 $E = \frac{\rho}{2\varepsilon_0} r$。
   * **物理意义**：在圆柱内部，电场强度和半径 $r$ 成正比，越往外电场越强（因为包围的电荷变多了）。

3. **第二阶段：在圆柱外部（$r \geq R$）**
   * 此时高斯罐头比带电圆柱粗，所以它把半径为 $R$ 的那一整段带电圆柱都装进去了。
   * 装进去的电荷量是固定的：$q_{\text{内}} = \rho \cdot \pi R^2 L$。
   * 代入高斯公式：$E \cdot 2\pi r L = \frac{\rho \cdot \pi R^2 L}{\varepsilon_0}$。
   * 消去两边的 $\pi, L$，得到 $E = \frac{\rho R^2}{2\varepsilon_0} \frac{1}{r}$。
   * **物理意义**：在圆柱体外面，电场强度和距离 $r$ 成反比，越往远走电场越弱。

4. **$E$-$r$ 曲线画法**：
   * 从 $0$ 到 $R$，画一条从原点出发斜向上的直线（正比例函数）；
   * 过了 $R$ 以后，画一条逐渐趋近于横轴的平滑下降曲线（反比例函数）。

## 习题 9-22

### 【答案】

已知两同心球面的半径分别为 $R_1 = 0.1\text{ m}$，$R_2 = 0.3\text{ m}$。小球带电 $q_1 = 10^{-8}\text{ C}$，大球带电 $q_2 = 1.5 \times 10^{-8}\text{ C}$。

根据球对称性，利用高斯定理求出各区域的电场强度 $E(r)$ 分布：
1. 当 $r < R_1$ 时：
   $$E = 0$$
2. 当 $R_1 < r < R_2$ 时：
   $$E = \frac{q_1}{4\pi \varepsilon_0 r^2}$$
3. 当 $r > R_2$ 时：
   $$E = \frac{q_1 + q_2}{4\pi \varepsilon_0 r^2}$$

根据电势与电场强度的积分关系 $V(r) = \int_{r}^{\infty} E\,\text{d}r$（设无限远处电势为零）：

**（1）求离球心 $r = 20\text{ cm} = 0.2\text{ m}$ 处的电势 $V_1$：**
由于 $R_1 < r < R_2$，电势为分段累加积分：
$$V_1 = \int_{r}^{R_2} E(R_1 < r < R_2)\,\text{d}r + \int_{R_2}^{\infty} E(r > R_2)\,\text{d}r$$
$$V_1 = \int_{r}^{R_2} \frac{q_1}{4\pi \varepsilon_0 r^2}\,\text{d}r + \int_{R_2}^{\infty} \frac{q_1 + q_2}{4\pi \varepsilon_0 r^2}\,\text{d}r$$
$$V_1 = \frac{q_1}{4\pi \varepsilon_0} \left( \frac{1}{r} - \frac{1}{R_2} \right) + \frac{q_1 + q_2}{4\pi \varepsilon_0 R_2}$$
$$V_1 = \frac{1}{4\pi \varepsilon_0} \left( \frac{q_1}{r} + \frac{q_2}{R_2} \right)$$

代入数据（取 $\frac{1}{4\pi\varepsilon_0} = 9 \times 10^9\text{ N}\cdot\text{m}^2\cdot\text{C}^{-2}$）：
$$V_1 = 9 \times 10^9 \times \left( \frac{10^{-8}}{0.2} + \frac{1.5 \times 10^{-8}}{0.3} \right)$$
$$V_1 = 9 \times 10^9 \times \left( 5 \times 10^{-8} + 5 \times 10^{-8} \right) = 9 \times 10^9 \times 10^{-7} = 900\text{ V}$$

**（2）求离球心 $r = 50\text{ cm} = 0.5\text{ m}$ 处的电势 $V_2$：**
由于 $r > R_2$，电场仅由外侧决定：
$$V_2 = \int_{r}^{\infty} \frac{q_1 + q_2}{4\pi \varepsilon_0 r^2}\,\text{d}r = \frac{q_1 + q_2}{4\pi \varepsilon_0 r}$$
代入数据：
$$V_2 = 9 \times 10^9 \times \frac{10^{-8} + 1.5 \times 10^{-8}}{0.5}$$
$$V_2 = 9 \times 10^9 \times \frac{2.5 \times 10^{-8}}{0.5} = 9 \times 10^9 \times 5 \times 10^{-8} = 450\text{ V}$$

---

### 【解析】

1. **电势的本质（叠加原理与积分公式）**
   * 电势是标量，具有超级好用的**叠加原理**。
   * 对于均匀带电球面，有一个非常著名的结论：
     * 如果你在球面**外部**（$r > R$），球面在你这里产生的电势，就等同于电荷全部集中在球心处的点电荷公式：$V = \frac{q}{4\pi \varepsilon_0 r}$。
     * 如果你在球面**内部**（$r < R$），球面内部任何一点的电场强度为零，因此内部各点的电势相等，都等于球面表面的电势：$V = \frac{q}{4\pi \varepsilon_0 R}$。
   * 掌握了这一结论，本题可以**完全不用做复杂的积分**，直接用公式叠加！

2. **第一问：求 $r=20\text{ cm}$ 处的电势**
   * 这个点距离球心 $20\text{ cm}$，处于两个球面的**中间**。
   * 它在小球面（半径 $10\text{ cm}$）的**外部**，所以小球面在这里产生的电势按外部公式算：$V_{\text{小}} = \frac{1}{4\pi \varepsilon_0} \cdot \frac{q_1}{r}$。
   * 它在大球面（半径 $30\text{ cm}$）的**内部**，所以大球面在这里产生的电势等于其表面的电势：$V_{\text{大}} = \frac{1}{4\pi \varepsilon_0} \cdot \frac{q_2}{R_2}$。
   * 总电势直接相加：$V = V_{\text{小}} + V_{\text{大}} = 9 \times 10^9 \times \left( \frac{10^{-8}}{0.2} + \frac{1.5 \times 10^{-8}}{0.3} \right) = 900\text{ V}$。

3. **第二问：求 $r=50\text{ cm}$ 处的电势**
   * 这个点距离球心 $50\text{ cm}$，在两个球面的**外面**。
   * 因此，它对于小球面和大球面来说都是“外部点”。
   * 总电势等于两个球面贡献的外部点电势之和：$V = \frac{1}{4\pi \varepsilon_0} \cdot \frac{q_1 + q_2}{r}$。
   * 代入计算：$V = 9 \times 10^9 \times \frac{2.5 \times 10^{-8}}{0.5} = 450\text{ V}$。

# 第10章 恒定磁场

## 习题 10-9

### 【答案】

已知空心柱形导体的内外半径分别为 $a$ 和 $b$，载有均匀分布的电流 $I$。

电流在横截面上的分布密度 $j$ 为：
$$j = \frac{I}{\pi(b^2 - a^2)}$$

根据轴对称性，选取半径为 $r$ 的同轴圆周为安培环路 $L$。根据安培环路定理：
$$\oint_{L} \boldsymbol{B} \cdot \text{d}\boldsymbol{l} = B \cdot 2\pi r = \mu_0 \sum I_{\text{内}}$$
$$B = \frac{\mu_0 \sum I_{\text{内}}}{2\pi r}$$

**（1）证明：在 $a < r < b$ 区域的磁感应强度公式：**
环路 $L$ 内部包围的电流仅为横截面半径从 $a$ 到 $r$ 这一环形区域内的电流：
$$\sum I_{\text{内}} = j \cdot \pi(r^2 - a^2) = \frac{I}{\pi(b^2 - a^2)} \cdot \pi(r^2 - a^2) = I \frac{r^2 - a^2}{b^2 - a^2}$$
代入安培环路定理中：
$$B = \frac{\mu_0}{2\pi r} \left( I \frac{r^2 - a^2}{b^2 - a^2} \right) = \frac{\mu_0 I}{2\pi (b^2 - a^2)} \frac{r^2 - a^2}{r}$$
**证毕。**

**（2）以 $a = 0$ 的极限情形检验公式：**
当 $a = 0$ 时，空心圆柱体变成了半径为 $b$ 的实心均匀带电圆柱体。代入公式得：
$$B = \frac{\mu_0 I}{2\pi(b^2 - 0)} \frac{r^2 - 0}{r} = \frac{\mu_0 I r}{2\pi b^2}$$
这与均匀实心导线内部的磁感应强度公式完全一致，公式通过检验。

**（3）当 $r \geq b$ 时：**
安培环路圈住了导体的全部电流，即 $\sum I_{\text{内}} = I$。
代入安培环路定理得：
$$B \cdot 2\pi r = \mu_0 I \implies B = \frac{\mu_0 I}{2\pi r}$$

---

### 【解析】

1. **核心工具：安培环路定理**
   * 在求对称性电流分布产生的磁场时，我们要用**安培环路定理**：$\oint B\text{d}l = \mu_0 \sum I_{\text{内}}$。
   * 选一圈半径为 $r$ 的同心圆环作为路径，左边积分项直接化简为：磁感应强度 $B$ 乘以圆周长 $2\pi r$。
   * 环路定理简化为：$B = \frac{\mu_0 \sum I_{\text{内}}}{2\pi r}$。问题的关键同样在于：**圆环内部漏过了多少电流**？

2. **如何计算部分电流 $I_{\text{内}}$ （比例法）**
   * 电流是均匀分布在导体的实体部分（环形横截面）上的。
   * 导体的实体横截面积为：$\pi b^2 - \pi a^2 = \pi(b^2 - a^2)$。
   * 我们画出的半径为 $r$ 的圆环（$a < r < b$），它包围的实体截面积为：$\pi r^2 - \pi a^2 = \pi(r^2 - a^2)$。
   * 因为电流均匀分布，根据面积比，被包围的电流为：
     $$\sum I_{\text{内}} = I \times \frac{\text{被包围面积}}{\text{总实体面积}} = I \frac{r^2 - a^2}{b^2 - a^2}$$
   * 把这个电流代入 $B = \frac{\mu_0 \sum I_{\text{内}}}{2\pi r}$，移项整理一下，就得到了题目要证明的公式。

3. **极限情形 $a = 0$ 是什么意思？**
   * $a = 0$ 意味着内径为零，即中间没有空心，变成了一根普通的实心导线。
   * 把 $a=0$ 套入证出的公式，得到 $B = \frac{\mu_0 I r}{2\pi b^2}$，这符合实心导线内部磁场和距离成正比的经典物理结论。

4. **当 $r \geq b$（在导线外面）时**：
   * 既然圆环已经画到了最外面，它自然把这根电缆里流过的所有电流 $I$ 都打包圈进去了，所以 $\sum I_{\text{内}} = I$。
   * 磁场公式就是无限长直导线外侧的经典公式：$B = \frac{\mu_0 I}{2\pi r}$。

## 习题 10-10

### 【答案】

已知同轴电缆由一内导体柱（半径 $a$）和一外导体管（内径 $b$，外径 $c$）组成。两部分电流大小均为 $I$，但方向相反，且均匀分布在横截面上。

根据安培环路定理：
$$B \cdot 2\pi r = \mu_0 \sum I_{\text{内}} \implies B = \frac{\mu_0 \sum I_{\text{内}}}{2\pi r}$$

**（1）当 $r < a$（导体圆柱内）时：**
环路只圈住了内导体柱的一部分电流。
内导体电流密度为 $j_1 = \frac{I}{\pi a^2}$，包围的电流为：
$$\sum I_{\text{内}} = j_1 \cdot \pi r^2 = I \frac{r^2}{a^2}$$
故该区域磁感应强度为：
$$B = \frac{\mu_0 I r}{2\pi a^2}$$

**（2）当 $a < r < b$（两导体之间）时：**
环路完全圈住了内导体的全部电流 $I$，但还没有圈住外导体的电流。
$$\sum I_{\text{内}} = I$$
故该区域磁感应强度为：
$$B = \frac{\mu_0 I}{2\pi r}$$

**（3）当 $b < r < c$（外导体内）时：**
环路完全圈住了内导体的电流 $I$（设方向为正），并且圈住了外导体（电流反向，设为负）的一部分电流。
外导体横截面积为 $\pi(c^2 - b^2)$，环路圈住的外导体电流大小为：
$$I_{\text{外包}} = I \frac{r^2 - b^2}{c^2 - b^2}$$
故净电流为：
$$\sum I_{\text{内}} = I - I_{\text{外包}} = I \left( 1 - \frac{r^2 - b^2}{c^2 - b^2} \right) = I \frac{c^2 - r^2}{c^2 - b^2}$$
故该区域磁感应强度为：
$$B = \frac{\mu_0 I}{2\pi r} \frac{c^2 - r^2}{c^2 - b^2}$$

**（4）当 $r > c$（电缆外）时：**
环路圈住了内、外导体的所有电流。因为两者大小相等、方向相反，相互完全抵消。
$$\sum I_{\text{内}} = I - I = 0$$
故该区域磁感应强度为：
$$B = 0$$

---

### 【解析】

这是一个关于同轴电缆的非常经典的物理模型，主要考察在四个不同区域内对安培环路定理的灵活应用。

1. **区域一：最里面的实心柱内部（$r < a$）**
   * 这里的电流均匀分布在半径为 $a$ 的实心圆面上。
   * 半径为 $r$ 的高斯环只圈住了面积比为 $\frac{r^2}{a^2}$ 的电流。
   * 圈住电流为 $I \frac{r^2}{a^2}$。带入公式得到 $B = \frac{\mu_0 I r}{2\pi a^2}$（磁场随半径线性增加）。

2. **区域二：两层导体之间的空隙（$a < r < b$）**
   * 在这个空档里，我们的安培环路把里面的整根内芯（半径 $a$）全部抱住了，所以它圈住的电流就是完整的 $I$。
   * 外面的管子还没碰到，所以不用考虑。
   * 直接套用公式，得到经典的直导线外磁场：$B = \frac{\mu_0 I}{2\pi r}$。

3. **区域三：在外层导体管的肉厚中（$b < r < c$）**
   * 这个区域比较复杂，我们圈住的东西有两部分：
     1. 最里面的整根内芯，电流为 $+I$（假设向上）。
     2. 外面管子从内壁 $b$ 到当前位置 $r$ 的这一层，它流过的是反向电流（向下）。
   * 外管被圈住的面积是 $\pi(r^2 - b^2)$，总截面积是 $\pi(c^2 - b^2)$。按比例，圈住的反向电流大小为 $I \frac{r^2 - b^2}{c^2 - b^2}$。
   * 把正向和反向电流相抵消，得到环路内的合净电流：$I - I \frac{r^2 - b^2}{c^2 - b^2} = I \frac{c^2 - r^2}{c^2 - b^2}$。
   * 代入公式，得到 $B = \frac{\mu_0 I}{2\pi r} \frac{c^2 - r^2}{c^2 - b^2}$。

4. **区域四：电缆的最外面（$r > c$）**
   * 这里最神奇，也是同轴电缆抗干扰的原理所在。
   * 我们的环路把整根电缆（内芯和外管）全部圈进去了。
   * 由于内芯流过去多少电流，外管就流回来多少电流，两者的电流等值反向，在宏观上电荷净流量为 $0$（$\sum I_{\text{内}} = I - I = 0$）。
   * 所以，同轴电缆外面的磁场强度 $B = 0$。也就是说，电缆不会对外界产生任何磁场干扰，外界也无法轻易干扰它！
